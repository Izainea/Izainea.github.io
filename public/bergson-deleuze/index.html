Bergson–Deleuze: duración, multiplicidad y devenir

No es una página para “leer sobre” Bergson y Deleuze. Es un conjunto de experimentos para sentir conceptualmente qué cambia cuando dejamos de pensar el tiempo como una línea homogénea, la multiplicidad como una colección y lo virtual como una simple posibilidad.

Experimento 01

Tiempo espacializado vs duración

Un reloj divide el tiempo en unidades homogéneas. Bergson pregunta qué se pierde cuando tratamos la experiencia temporal como si fuera una regla graduada. Este módulo contrapone una secuencia métrica con un flujo de memoria en el que cada instante altera el siguiente.

Manipula el modo de tiempo

En el modo duración, cada estado retiene parcialmente los anteriores: el presente no es un punto aislado, sino una condensación de pasado.

Experimento 03

Multiplicidad: cambiar coordenadas, cambiar relaciones

Una multiplicidad no es simplemente una colección de puntos. En este módulo no “añades nodos”: cambias parámetros internos de un espacio y observas cómo se reconfiguran distancias y trayectorias.

Deforma el espacio

La idea clave: una multiplicidad se define por relaciones internas, dimensiones, singularidades y modos de variación. No necesita ser reducida a una unidad superior que la contenga.

Experimento 05

Singularidades y bifurcaciones

Una singularidad no es una “cosa misteriosa”, sino un punto o régimen donde la organización del sistema cambia. Mueve el parámetro y observa cómo aparecen nuevos atractores estables.

Bifurcación tipo pitchfork

Para μ < 0 hay un único estado estable alrededor de 0. Cuando μ cruza 0, el sistema cambia cualitativamente y aparecen dos estados estables.

Modelo ilustrativo: dx/dt = μx − x³.

Experimento 06

Después de Deleuze: sensibilidad y devenir

Este módulo es explícitamente una reconstrucción contemporánea. No atribuye el atractor de Lorenz a Deleuze; lo usa para visualizar cómo una diferencia mínima puede producir trayectorias divergentes dentro de un mismo campo dinámico.

Dos trayectorias casi idénticas

Observa cuándo dejan de ser visualmente indistinguibles. La diferencia no “se añade” al sistema desde fuera: se despliega en la dinámica misma.
